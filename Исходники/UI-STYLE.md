# Экраны настроек

Визуальная основа — `outputs/Мои книги/Исходники/bridge.js`, классы `.settings`, `.settings-row`, `.secondary`, `.footer`. В Музыке нативные соответствия находятся в `PanelStyle.swift`.

- Между блоками 16 pt, подписи строк 13 pt, пояснения 11 pt, заголовок 20 pt bold.
- Подпись слева, переключатель справа; промежуток не меньше 10 pt.
- Дополнительная кнопка: 34 pt по высоте, внутренний отступ 12 pt, скругление 8 pt, спокойный светлый фон и короткий hover.
- Общая кнопка возврата с chevron применяется в настройках, прокси и очереди.
- Версия и GitHub — тихая строка внизу, 10 pt. Длинные формы прокручиваются внутри экрана, без обрезания кнопки сохранения.
- Hover использует существующий HoverButton с поддержкой Reduce Motion; смена страниц сохраняет fade.

Виджет Книг находится в активной отдельной разработке. Изменения сделаны только в Музыке; эта таблица фиксирует точки соответствия Swift и CSS для дальнейшего выравнивания двух приложений.
