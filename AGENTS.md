# Рабочие сборки macOS

- Вне `/Applications` хранить распакованные `.app` только в папках с суффиксом `.noindex` (достаточно такого имени у папки-предка).
- Системные временные каталоги `/tmp` и `$TMPDIR` допустимы для кратковременной сборки.
- Результат сборки — `build.noindex`. Временная упаковка и проверочные сборки также должны находиться внутри `.noindex`.
- Резервные версии сохранять ZIP-архивами, а не отдельными `.app` с номером версии.
- После тестовых запусков не оставлять их зарегистрированными как отдельные установленные приложения.
